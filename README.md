# TickFlow

MVP таск-менеджера в духе TickTick. SwiftUI + SwiftData, минимальная версия iOS 26.

## Запуск

```bash
unzip ~/Downloads/TickFlow.zip -d ~/Desktop
open ~/Desktop/TickFlow/TickFlow.xcodeproj
```

Перед первым запуском поменяй `PRODUCT_BUNDLE_IDENTIFIER` (сейчас `com.ahito.TickFlow`)
и выбери свою команду подписи в Signing & Capabilities.

## Что уже есть

- **Списки** — цвет, SF Symbol, счётчик активных задач, каскадное удаление задач вместе со списком.
- **Смарт-подборки** — Сегодня (с просроченными), Ближайшие 7 дней, Все, Завершённые.
- **Задачи** — заметки, срок с временем или без, приоритет, подзадачи, свайпы «Удалить» и «Сегодня».
- **Календарь** — сетка месяца с индикаторами загруженности, список задач выбранного дня, быстрое добавление на эту дату.
- **Поиск** — по названию, заметкам и названию списка.
- **Напоминания** — локальные уведомления для задач со временем, снимаются при выполнении и удалении.
- **Первый запуск** — три списка и три демо-задачи через `SeedService`.

## Структура

```
TickFlow/
├── TickFlowApp.swift        ModelContainer и точка входа
├── RootView.swift           TabView: Задачи / Календарь / Поиск
├── Models/                  TaskItem, TaskList, Subtask, Priority, TaskFilter
├── Services/                NotificationScheduler, SeedService
├── DesignSystem/            Color(hex:), палитра, CheckboxButton, форматирование дат
└── Features/                Home, Tasks, Lists, Calendar, Search
```

Проект использует синхронизированные группы Xcode (`PBXFileSystemSynchronizedRootGroup`):
новые файлы внутри папки `TickFlow/` попадают в таргет автоматически, редактировать
`project.pbxproj` не нужно.

## Осознанные упрощения

1. **Фильтрация в памяти.** `@Query` тянет все задачи, отбор идёт в вычисляемых свойствах.
   На сотнях задач это незаметно, на десятках тысяч — нет. Переход на `#Predicate` с
   `task.list?.id == id` стоит делать вместе с пагинацией.
2. **Нет повторяющихся задач.** Это отдельный RRULE-движок, а не поле в модели.
3. **Нет синхронизации.** Локальный store. Для CloudKit понадобится убрать уникальные
   ограничения и сделать все свойства опциональными или со значением по умолчанию —
   модели уже написаны с учётом этого.
4. **Ручная сортировка.** `sortOrder` есть в модели, но drag-and-drop в списке не подключён.
5. **`.glassEffect` в `QuickAddBar`** — единственное место с новым Liquid Glass API.
